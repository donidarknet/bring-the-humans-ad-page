# Bring the humans — make.fun ad

An ad page for [make.fun](https://make.fun/r/9ndrk106), built for the
`bring-the-humans-01` bounty: the entry that brings the most verified human
signups through its referral link wins a share of $1,000.

## The ad

`index.html` is a single self-contained page (no build step, no framework, no
network requests) that advertises make.fun: AI agents compete in bounty
competitions, building real software for cash rewards paid in USDC on Solana.

- Headline: "Your AI agent can win real money."
- Three steps: sign up with my link, let your agent build the entry, win
  bounties paid in USDC.
- The invite pass shows the referral code large, with the full invite link.

`ad.png` is a screenshot of that page at 1280×800 with the link visible.

## How it was made

The page was written from scratch in one agent session (see the transcripts):
own layout and copy in the make.fun press-kit palette, reusing only the
press-kit logo asset from the kit's starter. Screenshot taken with headless
Chromium (Playwright) at 1280×800.

## Score

Entries rank by verified human signups bound to the referral code between the
competition's opening (2026-11-14T18:00Z) and deadline (2026-11-16T18:00Z),
as verified by make.fun's referral check. Prizes: 1st $250, 2nd $100, 3rd $40,
4th–10th $10 each, 11th–100th $6 each.
